# قُرآن - رفيقك في رحلة القرآن الكريم

<div dir="rtl">

## نظرة عامة

**قُرآن** هو تطبيق جوال إسلامي مبتكر يساعدك في جدولة ختم القرآن الكريم، مع ميزات ذكية لتحفيزك على القراءة وتقليل الوقت المهدر في تطبيقات التواصل الاجتماعي.

## المميزات الرئيسية

### 📖 جدولة ختم القرآن
- **خطط مرنة**: اختر المدة التي تريد ختم القرآن فيها (7، 14، 30، 60، 90 يوماً)
- **تقسيم ذكي**: تقسيم بالأجزاء أو بالسور حسب تفضيلك
- **تتبع التقدم**: متابعة دقيقة لما أكملت من أجزاء وسور
- **تقدير الوقت**: حساب الوقت المتوقع للقراءة اليومية

### 🌙 الأذكار اليومية
- **أذكار الصباح والمساء**: مجموعة كاملة من الأذكار الصحيحة
- **الاستغفار والصلوات**: أذكار متنوعة على مدار اليوم
- **عداد تفاعلي**: تتبع عدد التكرارات بسهولة
- **تذكيرات ذكية**: إشعارات في أوقات الأذكار المناسبة

### 💚 التحفيز النفسي
- **رسائل تشجيعية**: رسائل لطيفة ومحفزة بعد كل إنجاز
- **سلسلة الأيام**: متابعة الأيام المتتالية من القراءة
- **إنجازات**: نظام شامل للإنجازات والجوائز
- **تنبيهات لطيفة**: "ما رأيك في قراءة بعض الآيات الآن؟" 📖

### 📱 مراقبة استخدام الجوال
- **تتبع الوقت**: حساب وقت استخدام التطبيقات يومياً
- **اكتشاف وسائل التواصل**: رصد الوقت المستهلك في تطبيقات التواصل الاجتماعي
- **اقتراح الأوقات**: توجيهك لاستغلال الوقت في القراءة بدلاً من التنقل بلا فائدة
- **تحديد الأهداف**: إمكانية وضع حد أقصى للاستخدام اليومي

### 📊 إحصائيات شاملة
- **إجمالي الآيات**: عدد الآيات التي قرأتها
- **الوقت الكلي**: إجمالي وقت القراءة
- **نسبة الإنجاز**: تتبع نسبة إكمال القرآن
- **الأجزاء المكتملة**: عرض مرئي للأجزاء التي أكملتها

## البنية التقنية

### التقنيات المستخدمة
- **Flutter**: إطار العمل الأساسي للتطبيق
- **Provider**: إدارة الحالة
- **SQLite**: قاعدة البيانات المحلية
- **Flutter Local Notifications**: نظام الإشعارات
- **Google Fonts**: خط Amiri العربي الجميل

## التثبيت والتشغيل

### المتطلبات
- Flutter SDK (3.0.0 أو أحدث)
- Android Studio / VS Code
- جهاز Android أو iOS (أو محاكي)

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/alfainternational/guran.git
cd guran
```

2. **تثبيت التبعيات**
```bash
flutter pub get
```

3. **تشغيل التطبيق**
```bash
flutter run
```

### إعداد الخطوط العربية (اختياري)

للحصول على أفضل تجربة، أضف خط Amiri:
```bash
mkdir -p assets/fonts
# قم بتنزيل خط Amiri من Google Fonts
```

## كيفية الاستخدام

### 1. إنشاء خطة ختم جديدة
- افتح التطبيق واضغط على "إنشاء خطة جديدة"
- اختر المدة المناسبة لك (مثلاً 30 يوماً)
- حدد نوع التقسيم (بالأجزاء أو بالسور)
- اضغط على "ابدأ الآن"

### 2. القراءة اليومية
- تحقق من قراءة اليوم في الصفحة الرئيسية
- اضغط على "ابدأ القراءة"
- عند الانتهاء، سجل عدد الآيات المقروءة
- استلم رسالة تحفيزية! 🌟

### 3. الأذكار
- انتقل لقسم "الأذكار" من القائمة السفلية
- اختر بين أذكار الصباح أو المساء أو الأذكار العامة
- اضغط على أي ذكر لبدء التسبيح
- استخدم العداد التفاعلي للتتبع

### 4. متابعة التقدم
- تحقق من الإحصائيات لرؤية تقدمك
- شاهد الأجزاء المكتملة
- احتفل بإنجازاتك!
